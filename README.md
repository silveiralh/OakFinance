# OakFinance

PWA de finanças pessoais — lançamento rápido offline, cartões e faturas com parcelas projetadas, orçamento 50/30/20, reserva de emergência e entradas automáticas (Open Finance, OFX/CSV, NFC-e). Visual **Aero moderno**.
